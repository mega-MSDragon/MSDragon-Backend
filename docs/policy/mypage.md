# 마이페이지 정책

확정 iOS 시안(`[iOS] 마이페이지`) 기준으로 마이페이지 화면 구성과 프로필 이미지 정책을 정의합니다.

---

## 화면 구성과 사용 API

| 영역 | 내용 | API |
|------|------|-----|
| 내 정보 | 아바타, 이름(부모는 관계명 표시 가능), 부모는 여행 MBTI 배지 | `GET /api/v1/users/me` |
| 내 정보 수정 | 아바타, 이름, 성별, 연령대 | `PATCH /api/v1/users/me` |
| 부모님 프로필 / 자녀 프로필 | 구성원 아바타, 관계명, 여행 MBTI 유형명 또는 `프로필 미입력` | `GET /api/v1/family` |
| 가족 추가하기 | 내 초대 코드 공유와 상대 코드 입력 | `POST /api/v1/family/code`, `POST /api/v1/family/matches` |
| 내 여행 MBTI 보기 | 부모 본인의 여행 MBTI 카드 | `GET /api/v1/parent-profiles/me` |
| 로그아웃 / 탈퇴 | 확인 다이얼로그 후 실행 | `POST /api/v1/auth/logout`, `DELETE /api/v1/users/me` |
| 알림 설정 | 토글 | **미구현** (아래 참고) |
| 버전 정보 | `1.0.0` | 클라이언트 로컬 값 |

`부모님 프로필`의 `프로필 미입력`은 `GET /api/v1/family`의 `members[].profileCompleted`가 `false`일 때 표시하고, 유형명 배지는 `members[].personalityResult.name`을 사용합니다. 여행 생성용 `GET /api/v1/trips/parent-candidates`를 마이페이지에서 호출하지 않습니다.

## 프로필 이미지

시안은 업로드가 아니라 **프리셋 아바타 선택**입니다. 서버는 이미지 파일을 저장하지 않고 식별자만 보관합니다. S3나 별도 스토리지가 필요하지 않습니다.

| 식별자 | 시안 |
|--------|------|
| `basic` | 액세서리 없는 기본 캐릭터 |
| `flower` | 꽃 장식 |
| `sunglasses` | 선글라스 |
| `straw_hat` | 밀짚모자 |

- **식별자는 서버가 정하고 클라이언트가 같은 값에 에셋을 맞춥니다.** 배경색은 리터치될 수 있어 색상 이름을 쓰지 않고 액세서리 기준으로 정했습니다.
- 선택 전이거나 지운 상태는 `null`이며 클라이언트가 기본 실루엣을 표시합니다.
- 수정 요청에서 필드를 **생략하면 기존 아바타를 유지**하고, `none`을 보내면 **지웁니다**. 프로필 수정이 부분 갱신 방식이라 `null`로는 지우기를 표현할 수 없어 요청 전용 값을 둡니다. 응답에는 `none`이 나가지 않습니다.
- 아바타는 같은 가족 구성원에게 공개됩니다. 마이페이지 프로필 카드와 효도 리포트 `부모님 한마디`에 같은 값을 사용합니다.
- 회원 탈퇴 시 `profile_image`를 `null`로 지웁니다.

아바타를 추가하거나 교체하려면 `UserProfileImage` enum, `docs/database/schema.dbml`의 `user_profile_image`, 이 문서, `docs/api/profile.md`, `docs/api/family.md`를 함께 갱신하고 클라이언트와 식별자를 맞춥니다.

## 알림 설정

시안에 `알림 설정` 토글(일정, 피드백 요청, 안전 알림)이 있으나 **서버는 구현하지 않습니다.** 푸시 알림과 기기 토큰 정책이 확정되지 않았고, 알림을 보내지 않는 상태에서 토글 값만 저장하면 동작하지 않는 설정을 서버가 들고 있게 됩니다.

- 토글 상태는 클라이언트 로컬에 보관합니다.
- 푸시를 구현할 때 기기 토큰 저장, 알림 종류별 수신 여부, 발송 트리거를 함께 설계하고 그때 서버 저장으로 옮깁니다.

## 여행 MBTI 다시 뽑기

시안 문구는 `여행 MBTI를 다시 뽑을까요? / 다시 뽑으면 지금 카드가 사라져요`입니다. **전용 초기화 API를 두지 않습니다.**

- `MBTI 다시 뽑기`를 누르면 클라이언트가 부모님 프로필 작성 화면으로 이동합니다.
- 재작성을 완료하면 `PUT /api/v1/parent-profiles/me`가 기존 값을 덮어씁니다.
- **재작성 중 이탈하면 기존 MBTI가 그대로 남습니다.** 버튼을 누른 즉시 삭제하면 미완성 상태에서 카드도 없고 프로필도 없는 상태가 되므로 데이터 안전을 위해 덮어쓰기 방식을 선택했습니다.
- 이미 만들어진 여행의 추천 스냅샷은 프로필을 다시 뽑아도 바뀌지 않습니다. `docs/policy/course-recommendation.md`를 따릅니다.
