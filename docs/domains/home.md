# Home Domain

Home 도메인은 확정된 홈 화면에 필요한 여러 도메인의 데이터를 한 응답으로 집계합니다.

## 책임

- 로그인 사용자의 역할과 여행 생성 가능 여부를 반환합니다.
- 부모 본인 또는 자녀에게 연결된 부모의 상세 프로필 완료 여부를 안내합니다.
- 진행 중·예정 여행만 홈 카드 형태로 반환합니다.
- 여행 생성 당시 부모 프로필 스냅샷으로 대표 테마와 여행 강도를 계산합니다.
- 월별 추천 도시 3개와 TourAPI 대표 이미지를 제공합니다.
- 국문 TourAPI에서 진행·예정 축제를 조회합니다.
- 추천 콘텐츠를 일 단위로 캐시하고 외부 API 장애 시 홈의 핵심 데이터를 유지합니다.

## 패키지 구조

```text
home
├── controller
├── dto
├── service
└── tourapi
```

## 관련 테이블

Home 전용 테이블은 없습니다. 아래 기존 데이터를 읽어서 응답을 구성합니다.

- `users`
- `family_members`
- `parent_profiles`
- `trips`

## 관련 API

- `GET /api/v1/home`

## 구현 결정

- 기존 `GET /api/v1/trips`는 기록 등 다른 화면에서도 사용하므로 반환 범위를 변경하지 않습니다.
- 홈 화면 전용 조회 계약은 `GET /api/v1/home`으로 분리합니다.
- 실제 푸시 알림 전송과 `나중에 하기` 서버 저장은 현재 범위에서 제외합니다.
- 월별 추천 도시 정책과 축제 캐시에는 DB를 사용하지 않습니다.
