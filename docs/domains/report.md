# Report Domain

Report 도메인은 참여 부모의 여행 피드백을 모아 여행별 효도 리포트를 생성하고 조회합니다.

## 책임

- 마지막 참여 부모의 피드백 제출과 동시에 리포트를 생성합니다.
- 중복 생성 요청에도 여행별 리포트 한 건만 유지합니다.
- 방문지 수, 부모 평균 별점, Tmap 이동거리, 중복 제거 태그를 집계합니다.
- 부모별 별점, 몸 상태, 자유 의견, 베스트 장소를 모두 제공합니다.
- 현재 코스를 기준으로 대표 이미지, 방문지 수, 이동거리를 갱신합니다.
- 여행 기간 또는 참여 부모 변경 시 기존 리포트를 삭제합니다.
- 완료 여행 목록과 기록 탭 상단 통계를 조회합니다.

## 관련 테이블

- `filial_reports`

`filial_report_stop_summaries`는 장소별 배지와 요약 정책이 정해진 뒤 구현합니다.

## 관련 API

- `POST /api/v1/trips/{tripId}/filial-report`
- `GET /api/v1/trips/{tripId}/filial-report`
- `GET /api/v1/records`

## 구현 결정

- 같은 가족 구성원 모두에게 생성·조회 권한을 허용합니다.
- 생성 API는 멱등이며 기존 리포트가 있으면 같은 ID를 반환합니다.
- 산식이 없는 기존 점수 필드는 삭제하지 않고 `null`로 유지합니다.
- 기록 목록은 `completed` 여행만 최신순으로 반환합니다.
- 리포트 대기 중인 여행은 제출된 부모 피드백만으로 현재 만족도를 계산합니다.
- 기록 탭 상단 평균 만족도는 여행별 평균을 동일 비중으로 집계합니다.
- 공유 이미지/PDF와 기록 상세 통합 API는 이번 범위에 포함하지 않습니다.
