# 효도 리포트 정책

참여 부모의 여행 피드백을 모아 여행별 효도 리포트를 생성하고 조회할 때 적용하는 기준입니다.

## 생성 조건과 시점

- 해당 여행에 참여한 부모가 모두 피드백을 제출하면 즉시 리포트를 생성합니다.
- 여행 마지막 날이어도 모든 부모가 제출했다면 생성합니다.
- 마지막 부모의 `POST /api/v1/trips/{tripId}/feedback/me` 처리 안에서 리포트 생성을 함께 수행합니다.
- `POST /api/v1/trips/{tripId}/filial-report`는 자동 생성 실패 복구와 클라이언트 재시도를 위한 멱등 API입니다.
- 이미 리포트가 있으면 새 행을 만들지 않고 같은 리포트를 반환합니다.

## 접근 권한

- 여행과 같은 가족에 속한 로그인 사용자는 리포트를 생성하고 조회할 수 있습니다.
- 다른 가족 사용자는 `403 Forbidden`으로 차단합니다.

## 집계 규칙

| 항목 | 계산 기준 |
|------|-----------|
| 방문지 수 | 현재 `trip_stops` 행 수 |
| 부모 만족도 | 참여 부모의 `overall_rating` 평균, 소수점 첫째 자리 반올림 |
| 함께 걸은 거리 | 값이 있는 `trip_days.route_total_distance_m` 합계를 km로 변환 |
| 좋았던 점 | 부모들이 선택한 GOOD 태그를 중복 제거하고 enum 순서로 정렬 |
| 개선할 점 | 부모들이 선택한 IMPROVEMENT 태그를 중복 제거하고 enum 순서로 정렬 |

- 경로 최적화 결과가 한 일자도 없으면 이동거리는 `null`입니다.
- 일부 일자에만 경로가 있으면 값이 있는 일자의 거리만 합산합니다.
- 화면에서는 Tmap 기반 대략적인 이동거리를 `함께 걸은 거리`라는 문구로 표시합니다.

## 부모별 피드백

- 부모가 2명이면 두 부모의 별점, 몸 상태, 자유 의견, 베스트 장소를 모두 반환합니다.
- 부모별 베스트 장소가 달라도 임의로 하나를 고르지 않습니다.
- 베스트 장소명은 피드백 제출 당시 스냅샷을 사용합니다.
- 베스트 장소 이미지 URL은 해당 방문지가 현재 코스에 남아 있을 때만 반환합니다.

## 대표 이미지

1. 부모별 베스트 장소 중 이미지가 있는 첫 장소
2. 이미지가 있는 첫 번째 방문지
3. 모두 없으면 `null`

## 미확정 값

아래 필드는 기존 ERD를 유지하되 계산 근거가 확정되기 전까지 `null`로 둡니다.

- 효도 지수
- 만족도 점수
- 다리 편안함 점수
- 잔소리 방지 점수
- 식사 만족 점수
- 화장실 안심 점수
- 수상 문구와 리포트 요약
- 걸음 수
- 공유 이미지 URL

## 코스 변경과 초기화

- 리포트가 생성된 뒤 마지막 날 코스가 바뀔 수 있으므로 `POST`와 `GET` 호출 시 대표 이미지, 방문지 수, 평균 별점, 이동거리를 현재 데이터로 다시 맞춥니다.
- 최초 `generatedAt`은 변경하지 않습니다.
- 여행 기간 또는 참여 부모 구성이 바뀌어 피드백을 초기화할 때 기존 리포트도 삭제합니다.
- 장소별 편안/주의 배지와 한 줄 요약은 근거 데이터가 없어 이번 구현에서 제외합니다.
- 공유 이미지/PDF 생성은 후속 작업으로 분리합니다.

## 기록 탭

- 기록 목록에는 서울 날짜 기준 상태 동기화 후 `completed`인 여행만 노출합니다.
- 여행 마지막 날은 `in_progress`이므로 기록 목록이 아니라 홈과 여행 모드에서 확인합니다.
- 완료 여행은 종료일과 여행 ID 내림차순으로 정렬합니다.
- 효도 리포트가 아직 없으면 `reportReady=false`를 반환하고, 제출된 부모 피드백이 있으면 해당 값만으로 현재 평균 만족도를 표시합니다.
- 상단 평균 만족도는 피드백이 하나 이상 제출된 여행별 평균을 먼저 계산한 뒤, 각 여행을 동일 비중으로 다시 평균냅니다.
- 완료 여행 수와 방문지 수는 피드백 제출 여부와 관계없이 모든 완료 여행을 집계합니다.
- 함께 걸은 거리는 완료 여행 중 저장된 Tmap 일자별 경로 거리만 합산하며, 경로 데이터가 전혀 없으면 `null`입니다.
- 가족 매칭 전 사용자는 빈 목록과 0건 통계를 받습니다.
